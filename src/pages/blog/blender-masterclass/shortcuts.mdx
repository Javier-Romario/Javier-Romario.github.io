## Defaults, and how to change them

The <b>default keymap</b> is "Blender" in
<b>Edit → Preferences → Keymap</b>. Switch it to <b>Industry Compatible</b> and most of these
change — that mode mimics Maya/Max conventions.

- <b>macOS:</b> Blender remaps <code>Ctrl</code> → <code>Cmd</code> automatically. <code>Ctrl+R</code>
  (loop cut) is <code>Cmd+R</code> on a Mac.
- <b>No numpad?</b> Enable <b>Preferences → Input → Emulate Numpad</b> so the top-row number keys
  act as Numpad 1/3/7 for views.
- <b>Customize:</b> right-click any menu item → <b>Assign Shortcut</b>, or edit directly in the
  Keymap preferences and <b>Export</b> your keymap to back it up.

## The 10 that matter most

```text
G / R / S      move / rotate / scale       ← 80% of modeling
Tab            object ⇄ edit mode
Ctrl+R         loop cut                    ← your best friend
Ctrl+B         bevel
E              extrude
Shift+A        add mesh
Ctrl+Z         undo (but don't live here)
Z              shading pie
Numpad .       frame selected
Shift+D        duplicate
```

If you only learn ten, learn those ten.
