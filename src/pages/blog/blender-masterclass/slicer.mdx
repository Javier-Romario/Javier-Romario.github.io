## The rule

<Formula math="Shell the thin, support the overhang" note="Walls give strength, infill gives weight, supports give overhangs somewhere to start." />

## The four dials

```text
LAYER HEIGHT   0.08mm fine  →  0.28mm draft     (detail vs time)
WALLS/SHELLS   2–4 perimeters                     (strength + watertightness)
INFILL         15% functional  →  100% solid      (weight vs strength)
SUPPORTS       on for anything over ~45° overhang  (cleanup cost)
```

## Orientation is a cheat code

Rotate the part **before** slicing. The right orientation:

- **Minimizes supports** — print overhangs upward-facing.
- **Puts layer lines perpendicular to load** — layers shear apart along the Z axis.
- **Hides layer lines** on the face people see.

<div class="poke">Drag LAYER HEIGHT and INFILL, then switch ORIENTATION. Watch the print-time readout
move. Thinner layers = more passes = more time; more infill = more plastic = more time.</div>

## FDM vs SLA at a glance

| | FDM | SLA |
|---|---|---|
| Cost | cheap | pricier resin |
| Detail | layer lines visible | near-invisible layers |
| Best for | functional parts, big prints | miniatures, jewelry |
| Supports | easier to remove | trickier, more cleanup |
