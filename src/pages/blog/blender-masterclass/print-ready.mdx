## The rule

## What "manifold" means

Think of your mesh as a balloon. Manifold = you could fill it with water and nothing leaks.
Blender has a built-in detector:

```text
Edit Mode  →  Select  →  Select All by Trait  →  Non Manifold
```

Anything it highlights is a leak. Fix with `F` (fill a hole), `M` (merge doubles), or
`Ctrl+N` (recalculate normals so all faces point outward).

<div class="poke">Toggle CUT A HOLE. Watch the readout flip from ✓ MANIFOLD to ✗ NON-MANIFOLD —
that's the exact check a slicer does. In Blender, you'd select that missing face and hit <code>F</code>.</div>

## Wall thickness: the number that matters

- **FDM (filament):** walls ≥ **0.8 mm** (about 2 nozzle widths). Thin details snap.
- **SLA (resin):** walls ≥ **1–2 mm**. Resin flexes when thin.
- Use the **Solidify** modifier to guarantee thickness instead of eyeballing it.

## Overhangs & the 45° rule

FDM prints layer on layer. Any surface steeper than **45° from vertical** needs support
material or it sags. Design self-supporting where you can — fillet the undersides.

## Export the STL

```text
File → Export → STL
  ✓ Selection Only (if you have one object)
  ✓ Apply Modifiers      ← non-negotiable, the slicer needs real geometry
  ✓ Scene Unit → Millimeter (or scale 1000 if you modeled in meters)
```
