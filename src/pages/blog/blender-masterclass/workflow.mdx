## The rule

## The modifier stack

In the **Modifiers** tab (wrench icon), each modifier sits in a stack. Blender evaluates them
**top to bottom** every frame. Change one, and everything below it recomputes live.

The three you'll live inside:

- **Bevel** — rounds edges so they catch light (and print cleanly).
- **Solidify** — gives a flat surface real wall thickness (non-negotiable for printing).
- **Subdivision Surface** — smooths the mesh without adding permanent geometry.

<div class="poke">In the demo, toggle modifiers on/off. Notice the mesh is <b>never edited</b> —
only the recipe changes. That's the whole point.</div>

## The hotkeys that matter

```text
TAB          edit / object mode        G  R  S      grab / rotate / scale
Ctrl+Z       undo (but don't live here)  Shift+A    add mesh
Ctrl+A       APPLY a modifier (bake it in) — do this LAST
Ctrl+1/2/3   add subdivision (level 1/2/3)
```

Only apply a modifier when you're truly done with it — usually right before export.

## Why this matters for print AND game

A **3D printer** needs your Solidify applied (it reads real walls). A **game engine** needs your
Subdivision collapsed to a sane triangle count. Because you modeled non-destructively, you can
apply different settings for each target from the **same base mesh**.
