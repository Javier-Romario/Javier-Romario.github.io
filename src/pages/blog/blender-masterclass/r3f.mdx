## The rule

<Formula math="useGLTF + &lt;primitive&gt; = your model in React" note="useGLTF loads the .glb, <primitive> mounts its scene graph. Everything else is just JSX." />

## The whole thing, in one breath

```tsx
import { Canvas } from '@react-three/fiber';
import { useGLTF, OrbitControls } from '@react-three/drei';

function MyModel() {
  const { scene } = useGLTF('/my-model.glb'); // one request
  return <primitive object={scene} />;
}

export default function Demo() {
  return (
    <Canvas camera={{ position: [0, 0, 6], fov: 45 }} dpr={[1, 2]}>
      <ambientLight intensity={0.4} />
      <pointLight position={[6, 6, 6]} intensity={40} />
      <MyModel />
      <OrbitControls autoRotate enableZoom={false} />
    </Canvas>
  );
}
```

Put the `.glb` in `/public`, import the component into Astro, and hydrate it with
`client:visible` so three.js only loads when the user scrolls to it.

<div class="poke">Drag the knot. Swap its color. This is exactly what your exported GLB will do —

## Lights, materials, animation

- **Lights** — `ambientLight` (fill) + `pointLight` or `directionalLight` (key). Your Blender
  materials come through the glTF's PBR maps automatically.
- **Materials** — tweak in JSX with `meshStandardMaterial`, or let the baked PBR maps do the work.
- **Animation** — glTF stores keyframes. Load them with `useAnimations`, or drive rotation with
  `useFrame((state, delta) => …)`.

## The performance rule

three.js is huge — that's the point of Astro islands. Hydrate with `client:visible`, keep the
`.glb` compressed, and your 3D scene costs nothing until it's actually on screen.
