## Why delta time

Frames are not equal length. A fast screen draws 144 frames per second, a slow one 30. Move the
ball 5px **per frame** and it flies on the fast screen, crawls on the slow one. Fix: move per
**second**, multiply by how long the last frame actually took.

## The skeleton

Every game you build has this exact shape. Memorise it once.

```js
let last = performance.now();
function loop(now) {
  const dt = Math.min((now - last) / 1000, 0.1); // seconds
  last = now;
  update(dt);   // move things
  render();     // draw things
  requestAnimationFrame(loop);
}
requestAnimationFrame(loop);
```

The <code>Math.min(…, 0.1)</code> caps dt. If the tab sleeps and comes back, dt could be 5
seconds and your ball teleports off-screen. Cap it.
