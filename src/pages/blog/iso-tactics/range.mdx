## BFS flood fill

A* finds *one* path to *one* goal. Move range wants *every* reachable tile — no goal. Different
tool: breadth-first search (BFS). It visits tiles in rings, counting steps as it goes.

<Formula math="spread until steps > movePoints" note="Ring 0 = the unit. Ring 1 = neighbours. Ring 2 = their neighbours… stop at the limit." />

```js
const q = [start];
const cost = new Map([[key(start), 0]]);
for (let i = 0; i < q.length; i++) {
  const cur = q[i];
  const c = cost.get(key(cur));
  if (c >= movePoints) continue;          // out of range
  for (const d of [[1,0],[-1,0],[0,1],[0,-1]]) {
    const n = { x: cur.x + d[0], y: cur.y + d[1] };
    if (blocked(n)) continue;             // walls + occupied tiles
    if (cost.has(key(n))) continue;       // already visited
    cost.set(key(n), c + 1);
    q.push(n);
  }
}
```

The `q` array is the trick: it grows while you read it. Each tile gets pushed once, so the
whole thing is fast even on big grids.

## The same code, two jobs

- **Move range** — flood fill from the unit, cap at move points.
- **Fog of war / vision** — flood fill from the unit, cap at sight range.
- **Danger zones** — flood fill from each enemy, overlay the results.
