## The damage formula

<Formula math="dmg = base + roll − cover" note="base = attacker's attack stat. roll = random (a d6 or a range). cover = defender's bonus. Clamp at 1 minimum." />

```js
function attack(attacker, defender) {
  const roll = 1 + Math.floor(Math.random() * 6);   // d6
  const dmg = Math.max(1, attacker.atk + roll - defender.cover);
  defender.hp -= dmg;
  if (defender.hp <= 0) defender.dead = true;
}
```

## The design rules

- **Randomness small.** A d6 swing of 1–6 on top of an atk of 5 means results are predictable
  but not solved. Too much randomness feels unfair; too little feels like arithmetic.
- **Cover is subtraction, not a %.** Players understand "−2" instantly. A "40% miss chance"
  feels like the game lied to them.
- **Always show the roll.** The dice readout builds trust — when you die, you see *why*.

formula is the same, and adding cover later is one `− cover` line.
