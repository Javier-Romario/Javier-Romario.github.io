<p class="lede">
  A tactics game is a <b>state machine</b>. Two states — your turn, enemy turn — and rules for
  who can act and when it flips. Everything else (graphics, input) just reads the current state.
</p>

## Two states, one loop

<Formula math="state: PLAYER ⇄ ENEMY" note="PLAYER → (end turn) → ENEMY → (AI done) → PLAYER. Forever." />

```js
let state = 'PLAYER';
let ap = 3;   // action points this turn

function act(cost, name) {
  if (state !== 'PLAYER' || ap < cost) return;  // guard
  ap -= cost;
}

function endTurn() {
  state = 'ENEMY';
  aiTakeTurn();      // enemy acts...
  state = 'PLAYER';  // ...then back to you
  ap = 3;            // reset points
}
```

## Why a state machine

Because you can ask questions like <code>if (state !== 'PLAYER') return;</code> and suddenly
the enemy's turn is immune to your clicks. One variable, checked everywhere, prevents a hundred
bugs. The UI (buttons, highlights) just mirrors the state.

## In GRIDRUNNER

Same machine, plus a `winner` state on top. And "acted" flags per unit (each unit gets one go
per turn). The AI turn is just a timed loop that runs each enemy unit one at a time.
