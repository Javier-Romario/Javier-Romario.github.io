## The score: f = g + h

Each tile gets a score. The search always expands the tile with the lowest score.

<Formula math="f = g + h" note="g = steps already taken (known). h = Manhattan distance to the goal (guess). f = best guess of total cost." />

- `g` — real cost so far. Start tile = 0, each step +1.
- `h` — **heuristic**: the Manhattan distance to the goal. Never overestimates, so A* stays optimal.
- `f` — lower is better. The search greedily heads toward the goal but won't cheat through walls (it backtracks when `g` proves a detour is needed).

```js
// the whole idea, compressed
while (open has tiles) {
  cur = tile in open with lowest f;
  if (cur === goal) return reconstructPath();
  for (each neighbour not blocked) {
    g2 = g(cur) + 1;
    if (g2 < g(neighbour)) {   // found a cheaper route
      neighbour.cameFrom = cur;
      g(neighbour) = g2;
      f(neighbour) = g2 + manhattan(neighbour, goal);
      open.add(neighbour);
    }
  }
}
```
