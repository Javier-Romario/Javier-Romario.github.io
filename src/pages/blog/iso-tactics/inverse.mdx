## Un-rotate, un-squash

Start from the two projection lines and solve for `x` and `y`. Two equations, two unknowns,
high-school algebra.

<Formula math="x = (sx / 32 + sy / 16) / 2" note="Divide by the half-widths, add, halve. Gives the x coordinate." />

<Formula math="y = (sy / 16 − sx / 32) / 2" note="Subtract instead of add. Gives the y coordinate." />

```js
function toTile(sx, sy, ox, oy) {
  const px = sx - ox;   // remove origin offset
  const py = sy - oy;
  const x = (px / 32 + py / 16) / 2;
  const y = (py / 16 - px / 32) / 2;
  return { x: Math.floor(x), y: Math.floor(y) };
}
```

`Math.floor` snaps the pixel to the tile it's standing on. That's how a continuous mouse
position becomes a discrete tile.

## Why this is the whole game

Every click in GRIDRUNNER is this function. Select a unit, pick a move, target an enemy — all
of it is "where did the mouse point?" → `toTile()` → "what's there?".
